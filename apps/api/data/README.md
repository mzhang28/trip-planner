# Airport data

`openflights-airports.dat` is the OpenFlights Airports Database downloaded from
https://openflights.org/data.php on 2026-08-11.

OpenFlights makes the database available under the Open Database License (ODbL),
with individual contents under the Database Contents License. The application
uses the IATA code, airport name, city, country, coordinates, and IANA time zone.
The data is not suitable for navigation.

Source: https://github.com/jpatokal/openflights/blob/master/data/airports.dat
